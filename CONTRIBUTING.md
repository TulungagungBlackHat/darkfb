# Contributing

Terima kasih sudah mau kontribusi ke Tulungagung Black Hat!

## Cara Kontribusi
1. Fork repo
2. Buat branch `feat/nama-fitur`
3. Commit dengan pesan jelas
4. Push & buat Pull Request

## Aturan
- Hanya untuk edukasi & defensive security
- Jangan submit tool untuk merugikan orang lain
- Sertakan disclaimer jika tool sensitif
- Gunakan Python 3.8+ dan dokumentasi jelas

Always Smile :)
